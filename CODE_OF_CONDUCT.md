# Código de conduta

Participe com respeito, clareza técnica e foco em colaboração. Assédio, discriminação, exposição de dados privados e conteúdo criado para contornar autenticação, CAPTCHA ou controles de acesso não são aceitos.

Discussões devem incluir evidências reproduzíveis sem credenciais ou dados pessoais. Comportamentos inadequados podem ser reportados pelos canais privados indicados em `SECURITY.md`.
